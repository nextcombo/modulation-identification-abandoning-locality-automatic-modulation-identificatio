# [Modulation Identification] Abandoning Locality: Automatic Modulation Identification Based on Frame-wise Embeddings with Transformer [with Python Code]

Automatic Modulation Recognition (AMR) technology is considered an effective technique for non-cooperative and intelligent communication. This paper proposes an improved transformer-based AMR method—Feed-Forward Embedding with Assisting Transformer (FEA-T)—which aims to extract global correlation features of signals to achieve higher classification accuracy and lower time overhead. To enhance the global modeling capability of the transformer, a frame embedding module (FEM) is designed, which aggregates more samples into a token during the embedding phase to generate more efficient token sequences. By analyzing the representation capabilities of each transformer layer, we propose a best frame length that achieves a good balance between speed and performance. Additionally, we design a novel dual branch gate linear unit (DB-GLU) scheme for the feed-forward network of the transformer to reduce model size and improve performance. Experimental results on the RadioML 2018.01 A dataset show that compared to other methods, the proposed method achieves higher recognition rates, shorter recognition times, and higher recognition efficiency, demonstrating its promising application prospects.
Introduction  
The goal of adaptive modulation recognition (AMR) is to identify the modulation scheme from received signals under unknown channel and noise conditions. As a key technology in communication receivers, AMR has been widely studied in various military and civilian applications [1]. Traditional AMR methods can be divided into likelihood-based (LB) methods and feature-based (FB) methods. The LB method estimates the modulation type by calculating the corresponding likelihood. These methods are computationally expensive and typically require ideal parameter estimation of the transmission environment. The FB method performs classification using manually engineered features. These methods can achieve suboptimal performance at lower computational complexity but require robust feature engineering. In recent years, a large number of deep learning-based AMR algorithms have been proposed, significantly outperforming traditional methods.
Early studies [4], [5], [6] tended to construct DL-AMR models based on Convolutional Neural Networks (CNN) to distinguish modulation patterns by extracting local features. However, strong local inductive biases limited the performance of CNNs. Methods based on Recurrent Neural Networks (RNN), which continuously extract temporal features, have outperformed CNN-based methods at a higher time cost [7]. There have been more approaches proposed to combine the joint harvester CNN with RNN to fully leverage both temporal and spatial information simultaneously [8], [9], [10], [11]. Although these methods can achieve state-of-the-art accuracy, they require large amounts of parameters, making it difficult to balance performance and time cost.
Transformer has become the de facto architecture for natural language processing tasks and has achieved great success in computer vision and speech separation [12]. Compared to RNN and CNN, Transformer parallelly processes sequence inputs and replaces local induction bias with multi-head self-attention (MHSA) mechanism. In this way, more common global features can be extracted. Recently, high-performance methods based on transformers for AMR have been developed [13], [14]. However, since these methods often contain CNN or RNN blocks for feature embedding, they still require significant computational complexity and memory consumption due to the presence of strong induction bias or serial forward propagation. Generally, modulation signals usually transmit bit sequences without semantic information, and each modulation symbol appears uniformly in the waveform with equal probability. Therefore, the more valuable features for the AMR task should be evenly distributed across the waveform. The extraction of these features should not be within the scope of local bias assumption.
In these various DL-based AMR methods, there has been almost no attempt to globally analyze signals. In this context, we propose a transformer-based AMR method called the Frame-by-Frame Embedding Assisted Transformer (FEA-T), which achieves both high performance and rapid execution speed with global functionality assistance. Specifically, to improve accuracy and overcome locality limitations, we design a framework-embedded module (FEM) for global feature embedding. Additionally, a dual-branch gating linear unit (DB-GLU) developed for Transformer is introduced to alleviate the issue of model size and enhance classification performance. Furthermore, we derive the optimal frame length for the FEM module to fully activate the representation capabilities of the Transformer, thereby achieving optimal accuracy. The contributions of this study are summarized as follows:
1) This paper proposes using global features for AMR and provides a feasible solution that avoids the defects of local features, meeting the requirements of AMR tasks for fast and high-performance execution.
2) We introduce a practical structure modification for the Transformer, making it more suitable for lightweight deployment in AMR applications.

Conclusion
In this letter, an effective transformer-based AMR method is proposed to achieve higher accuracy and faster execution speed simultaneously. Our key strategy is to redesign the feature embedding module for the AMR task and implement a lighter-weight Transformer structure. During the feature embedding stage, we propose the FEM module for global feature embedding. Moreover, we develop the optimal frame length for the Transformer to achieve optimal accuracy. Additionally, we design the DB-GLU structure to realize the FFN of the Transformer, obtaining better performance and smaller model size than traditional Transformer structures. Experimental results show that the proposed model outperforms other methods in terms of classification accuracy and execution speed, making it more suitable for real-time communication applications.
